# HorizonXT Hackathon - Rules & Guidelines Summary

## About HorizonXT
HorizonXT is a 36-Hour National Level College Hackathon hosted at SRM Institute of Science and Technology, Tiruchirappalli. The event features 22+ official research problem statements in fields such as EVs, Industry 4.0, Healthcare AI, Robotics, and CleanTech.

**Key Dates:**
- **Registration Opens:** October 5
- **Abstract Submission Deadline:** October 16
- **36-Hour Hackathon Event:** October 24–26, 2026

## Rules & Regulations

### 1. Squad Architecture & LinkedIn Requirement
- Teams must consist of **1 to 4** registered participants.
- Every team member **MUST** provide a valid, active LinkedIn Profile URL during registration.
- All members must be enrolled students in an accredited educational institution. Inter-college and multi-disciplinary teams are strongly encouraged.

### 2. Abstract Submission
- Teams must select one problem statement from the official tracks.
- The abstract MUST be provided as a **Google Drive link** containing a **.docx format document ONLY**.
- Google Drive link permission must be set to "Anyone with the link can view".
- Formats like PDF, TXT, or images will lead to automatic disqualification.

### 3. Registration & Participation Fees
- Abstract submission is **100% FREE** for all teams.
- Participation for SRMIST / SRM Students is **100% FREE**.
- For non-SRM / external college teams, each member pays **₹500 ONLY AFTER** their abstract is shortlisted.
- Shortlisted teams will work on the SAME problem statement they submitted for during the 36-hour physical hackathon.

### 4. 36-Hour Sprint & Code Integrity
- All production code, datasets, models, and prototypes must be engineered within the official 36-hour on-site sprint window.
- Open-source libraries and foundational AI models are permitted if disclosed in the GitHub repository.
- Squads retain **100% full intellectual property ownership** of all code and artifacts engineered during HorizonXT.

### 5. Final Submission & Demo
- Every squad must submit a public GitHub repository link and working live demonstration before the 36-hour timer expires.
- Shortlisted squads will present a 5-minute live demonstration + 3-minute technical Q&A on the main stage on October 26.
